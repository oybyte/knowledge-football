第一步用攻防、联赛基准、战术、伤停、战意、赛程和环境形成基础进球区间；第二步用大小球盘口、水位和机构共识验证或修正；第三步列出反向因素并按强、中、弱调整容错。盘口不得单独替代基本面。

## GOAL-009 实验轨：分歧盘极端水位观察

| 执行字段 | 实验轨要求 |
|---|---|
| track | experimental |
| lifecycle | experimental |
| trigger | 总进球盘口分歧达到至少半球，且至少两家核心机构在同一更低盘口上对应方向水位不高于0.65，无异常跳盘 |
| thresholds | 触发条件需同时满足盘口分歧、核心机构共识和无异常跳变 |
| action | 维持原盘口信号等级，记录进球区间向极端水位方向偏移半档的实验观察 |
| output_effect | 只作为独立实验提示，不计入正式轨权重，不改变正式轨主结论 |
| exceptions | 单机构极端值、异常盘、基本面强反向或数据不足时不触发 |
| validation | 同场景至少10场，预先定义核心区间命中率与方向命中率 |

## GOAL-010 实验轨：杯赛阶段基准修正

| 执行字段 | 实验轨要求 |
|---|---|
| track | experimental |
| lifecycle | experimental |
| trigger | 欧战资格赛或杯赛淘汰赛首回合，且没有明确强防守题材 |
| thresholds | 基准线尝试上调0.25档，并同步重算深浅盘边界 |
| action | 记录进球基准上调后的独立观察，不覆盖通用基准 |
| output_effect | 单独提示，不计入正式轨大小球权重，不改变正式轨主结论 |
| exceptions | 决赛、次回合生死战、单场决胜或明确防守导向时不触发 |
| validation | 同场景至少10场，大小球方向相对基准提升至少10% |
