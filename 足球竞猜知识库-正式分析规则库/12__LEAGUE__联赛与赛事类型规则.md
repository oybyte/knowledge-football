## LEAGUE-008 实验轨：淘汰赛首回合平局强化

| 执行字段 | 实验轨要求 |
|---|---|
| track | experimental |
| lifecycle | experimental |
| trigger | 两回合淘汰赛首回合且三项凯利最大差值不超过0.05 |
| thresholds | 平权条件与首回合场景必须同时满足 |
| action | 观察平局顺位前置、总进球区间下调半档和小球风险变化 |
| output_effect | 单独输出实验观察，不把平局写成正式轨唯一方向 |
| exceptions | 次回合、单场决胜、决赛或非平权盘不触发 |
| validation | 同场景至少10场，平局相对基准提升至少12% |

## LEAGUE-009 实验轨：正式淘汰赛中立场进球压制

| 执行字段 | 实验轨要求 |
|---|---|
| track | experimental |
| lifecycle | experimental |
| trigger | 正式淘汰赛或资格赛在符合中立场定义的场地进行，且不是友谊赛或热身赛 |
| thresholds | 中立场条件、正式赛事条件和场地氛围条件必须同时满足 |
| action | 观察总进球基础预期下调半档、小球信号提升半级及0-0进入备选梯队 |
| output_effect | 单独输出实验提示，不改变正式轨总进球主结论 |
| exceptions | 主客场赛制、商业热身赛或中立场条件不完整时不触发 |
| validation | 同场景至少10场，大小球相对基准提升至少10% |

## LEAGUE-010 实验轨：低稳定性赛事盘赔降权

| 执行字段 | 实验轨要求 |
|---|---|
| track | experimental |
| lifecycle | experimental |
| trigger | 低稳定性联赛、赛季前段或淘汰赛首回合等预定义低稳定场景 |
| thresholds | 场景匹配必须完整，且盘赔与基本面存在可比较数据 |
| action | 观察盘赔权重降低、基本面权重提高后的让球方向变化 |
| output_effect | 只作为实验提示，不改变正式轨权重结构 |
| exceptions | 高稳定主流联赛、数据缺失或强基本面碾压场景不触发 |
| validation | 同场景至少10场，让球方向相对基准提升至少8% |
