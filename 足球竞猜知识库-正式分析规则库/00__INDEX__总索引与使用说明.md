# 足球比赛分析正式规则库

本库用于：在联网获取比赛背景信息后，接收用户手动输入的初盘、即盘、欧赔、凯利、大小球及走势数据，按照固定流程完成结构化分析、规则匹配、冲突裁决、风险降级和复盘记录。

联网信息只用于确认赛制、联赛、球队状态、伤停、首发、天气、场地和赛程等背景。盘赔与走势以用户提供的数据为准；缺失数据不得猜测填充。

## 使用顺序

1. 读取 `01__INPUT__研究范围与输入数据规范.md`，检查输入完整性和截止时间。
2. 按 `02__PROC__V9.1执行流程重编版.md` 执行六阶段流程。
3. 用 `03__CHECK__赛前强制检查清单.md` 做逐项勾稽。
4. 按联赛、赛制、盘口、时间节点和市场维度检索 `04` 至 `15` 规则模块。
5. 用 `16__RULE-INDEX__新规则总索引.md` 区分正式轨与实验轨。
6. 用 `18__REL__规则关系登记表.md` 处理先决、互斥、补充和冲突关系。
7. 严格按 `13__SCORE__比分梯队与输出约束.md` 输出正式轨主结论和实验轨独立提示。

## 双轨原则

正式轨规则用于主分析。实验轨规则只在满足场景条件时单独展示，不计入正式轨权重，不改变正式轨主结论。实验规则必须记录样本数、验证指标和当前阶段，达到门槛并完成两次确认后才可转为正式轨。

## 输入输出边界

本库不生成缺失的盘口、赔率、凯利或大小球数据，不以单一机构、单一水位或单场结果直接形成确定性判断。分析结果是逻辑参考，必须保留风险等级、数据缺口和不确定性。
