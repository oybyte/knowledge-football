## 边界

平权不是“必平”或“无方向”，而是提高均势风险并限制单选表达。凯利必须与欧赔、亚盘、大小球和基本面交叉验证。

## KELLY-007 实验轨：平权盘极端场景观察

| 执行字段 | 实验轨要求 |
|---|---|
| track | experimental |
| lifecycle | experimental |
| trigger | 平权盘同时出现极端盘口、极端水位或特殊赛事属性，且正式轨没有明确覆盖分支 |
| thresholds | 记录平权差值、盘口档位、机构共识和赛事属性，不新增正式权重阈值 |
| action | 单独记录平权观察结论，比较平局、主胜和客胜的实际顺位变化 |
| output_effect | 只作实验提示，不改变正式轨排序、权重或单选禁令 |
| exceptions | 数据不足、非平权盘或已有正式规则明确覆盖时不触发 |
| validation | 同场景至少10场，预先定义排序命中和比分梯队覆盖指标 |
