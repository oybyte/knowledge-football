# 临盘与持续走势规则

## LIVE-001 采样标准

| 执行字段 | 统一要求 |
|---|---|
| inputs | 使用本规则主题对应的用户手动盘赔数据与联网背景字段；缺失时降级 |
| trigger | 仅在本节明确的场景与条件同时满足时触发 |
| thresholds | 以本节列出的数值、档位、时间节点和共识条件为准；临界值按保守侧处理 |
| action | 执行本节规定的判断、修正或风险标记 |
| output_effect | 只影响本主题对应的方向、区间、权重或风险，不跨域强行传导 |
| exceptions | 先检查本节边界、禁用条件、数据不足和冲突门禁 |
| relations | 由`18__REL__规则关系登记表.md`中的正式轨/实验轨关系约束 |

走势至少记录初盘、中盘和临盘节点；持续走势需方向一致且存在连续节点。单点急变、来回震荡和单机构变动不满足持续条件。
