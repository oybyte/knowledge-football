# 赛前强制检查清单

## 输入完整性

- [ ] 对阵、联赛、赛制、时间和主客场已确认
- [ ] 数据截止时间已标注
- [ ] 伤停、首发、战意和赛程背景已核对
- [ ] 初盘、即盘、机构和时间序列已录入
- [ ] 欧赔、凯利、大小球字段完整或缺口已说明
- [ ] 核心机构不少于三家，异常机构已标记

## 场景匹配

- [ ] 已区分联赛、杯赛、淘汰赛首回合、次回合和单场决胜
- [ ] 已判断主客场或中立场
- [ ] 已判断联赛稳定性和赛季阶段
- [ ] 已完成强弱层级和合理盘口定位
- [ ] 核心伤停、战意或赛制驱动优先于盘口解释

## 正式轨执行

- [ ] 先完成胜平负凯利与平权检查
- [ ] 亚盘已完成初盘定位、有效异动和阻诱双向校验
- [ ] 大小球已完成基本面基线、盘口风控和反向校验
- [ ] 已执行欧亚联动、盘口分歧和持续走势检查
- [ ] 已执行禁用条件、冲突门禁和叠加上限
- [ ] 极致平权未输出胜平负单选

## 实验轨执行

- [ ] 已检索适用实验轨规则
- [ ] 每条实验规则已标明编号、触发条件和样本进度
- [ ] 实验轨未计入正式轨权重
- [ ] 实验轨与正式轨分歧已单独提示
- [ ] 无适用实验规则时已明确说明

## 输出

- [ ] 正式轨主结论与实验轨提示分开
- [ ] 核心数据已表格化
- [ ] 比分梯队覆盖主胜、平局和客胜的必要范围
- [ ] 最多给出两个明确方向
- [ ] 已列出主要风险、缺失数据和不确定性
