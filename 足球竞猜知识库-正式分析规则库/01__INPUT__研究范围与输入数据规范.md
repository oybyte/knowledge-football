# 研究范围与输入数据规范

## 研究范围

本库服务于个人足球比赛数据研究。联网资料用于比赛背景确认；初盘、即盘、欧赔、凯利、大小球及变化走势由用户手动输入。所有分析以赛前数据截止时点为界。

## 必填输入

| 类别 | 字段 |
|---|---|
| 比赛身份 | 主队、客队、联赛、赛制、比赛时间、主客场或中立场 |
| 背景 | 近况、赛季阶段、战意、伤停、首发、赛程、天气和场地 |
| 亚盘 | 受注初盘、即盘、机构、让球方向、水位、每个时间节点 |
| 欧赔 | 初赔、即赔、机构、返还率、离散度、变化时间 |
| 凯利 | 数据来源、三项数值、均值、中位值、极差、变化节点 |
| 大小球 | 初盘、即盘、大球水位、小球水位、机构共识、变化时间 |
| 截止信息 | 最后采样时间、数据是否临盘、缺失字段说明 |

## 口径

- 初盘采用受注初盘；试探性开盘只作为背景。
- 变化幅度按同一机构初盘到即盘计算，不跨机构比较绝对水位。
- 核心机构池至少三家；不足三家时所有盘口信号降为弱信号。
- 凯利优先使用同一来源的官方数据；自行计算时统一返还率口径，再比较均值和中位值。
- 单机构与机构池均值偏离明显时先标记异常，不直接纳入共识。
- 交易所成交热度只作筹码背景，不替代核心机构与凯利判断。

## 缺失数据处理

缺少一个核心维度时，分析可以继续，但必须降低信号等级并标明缺口。缺少盘口时间序列时，不得执行持续走势、升降盘幅度和临盘生命线规则。缺少基本面关键字段时，不得用盘口叙述替代基本面结论。
