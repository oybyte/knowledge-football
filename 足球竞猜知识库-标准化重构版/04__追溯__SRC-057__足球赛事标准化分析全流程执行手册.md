## 第一部分 总则与基础规范

### 一、底层元规则（体系最高准则）

1. **规则更新铁律**：固化新规则时只能新增，不能修改原有规则；确需修改原有规则，必须经过人工二次确认。
2. **固化升级流程**：新规则先进入「试运行规则库」，同场景累计验证≥10 场、命中率较基准提升达标（平局规则≥12%，大小球规则≥10%），经二次确认后升级为正式固化规则。
3. **复盘铁律**：所有复盘必须严格站在赛前视角，先还原推演结论，再对照赛果验证；严禁赛后上帝视角倒推解释。
4. **二次确认原则**：所有规则固化、原有规则修改，均需两次确认后执行，单次确认不生效。
5. **规则边界原则**：每条规则均有适用场景与禁用反例，禁止跨场景泛化套用；边界存疑时默认不触发，适用通用规则。
6. **版本号管理**：规则迭代版本号递增，每次分析标注适用版本；旧版本仅作复盘对照，不用于新比赛分析。
7. **冲突兜底机制**：规则优先级无法判定时默认不触发，按通用规则处理；同类冲突累计≥3 次启动优化评估。
8. **编号溯源体系**：每条固化规则分配唯一编号（R01-R41），新增规则顺延编号；核心结论必须标注对应规则编号，全程可追溯。
9. **赛果时间界定**：所有分析、复盘、命中率统计，均以 90 分钟常规时间（含伤停补时）为准；加时赛、点球大战不计入常规赛果。
10. **权重修正叠加上限（R38）**：所有维度的权重、区间修正，叠加上限不得超过 1 档；多规则同向可在 1 档内收窄区间精度，不得突破上限；试运行规则不计入叠加。

### 二、数据基准规范

1. **核心机构与权重**
   - 头部 4 家：澳*（权重最高）、36*、威*、立*；含澳彩的 3 家及以上同向变动为标准有效异动，不含澳彩则信号降半级。
   - 辅助机构：Interwetten 等，仅作趋势验证；交易所数据仅作筹码热度参考，不纳入凯利计算与平权判定。
2. **凯利计算规范**
   - 优先级：官方凯利 > 自行计算；自算统一以 89% 返还率为基准，跨机构对比前先做返还率归一化校准。
   - 同步计算平均值与中位值交叉验证；单家偏离均值≥0.10 判定为异常值，不参与均值计算；均值与中位值差值≥0.03 时，信号降半级。
   - 走势斜率：连续 3 个节点加速下行，权重提升半级；匀速下行不调整；赔率降、凯利升的背离场景不调整权重。
3. **水位标准**
   - 变动幅度统一按**同机构初盘→即盘的相对值**计算，不跨机构比绝对值。
   - 档位定义：高水≥0.95，中水 0.85-0.94，低水≤0.84。
   - 水位差异常：差≥0.30 信号可信度提升；差≤0.10 信号降半级。
4. **初盘定义**：统一采用**受注初盘**（开赛 72 小时左右稳定盘口）为分析基准；开盘试探盘仅作背景参考。
5. **时间权重分配**：早盘（72h+）20%，中盘（24-72h）30%，临盘（2h 内）50%；按时间加权计算综合变动幅度。
6. **历史交锋规范**：有效范围为近 2 个赛季正式比赛，权重≤20%；主帅更迭、阵容大换血后交锋权重清零。
7. **异常机构剔除**：返还率偏离 5 家均值≥5%，或返还率＜85%/＞95%，降为辅助参考级。
8. **必发数据规则**：成交量单边占比＞70% 且凯利不同步下行，判定为筹码对冲，不调整权重；必发数据权重≤10%，不得推翻核心判定。
9. **升班马校准**：单支升班马以上一级联赛中下游数据为基准；双升班马对阵以次级联赛数据为基准，信号降半级。
10. **数据口径标注**：分析开头需明确凯利来源、核心机构范围、联赛基准线统计周期。

### 三、联赛与场景基础定义

1. **联赛稳定性层级**

表格

| 层级 | 包含赛事 | 对应规则 |
| --- | --- | --- |
| 高稳定性 | 五大联赛、巴甲、阿甲、葡超等主流顶级联赛 | 高稳联赛平局权重 2 条 |
| 低稳定性 | 北欧联赛、东欧次级联赛、南美杯赛、欧战资格赛中下游、韩国 K1/K2 联赛 | 低稳联赛平局 / 冷门权重 2 条 |

>
> 注：韩国 K1/K2 联赛专属规则（R23、R24）独立生效，不受稳定性层级影响，仅平局 / 冷门通用权重规则按低稳定性联赛标准执行。

2. **联赛阶段修正**：赛季初前 5 轮进球上调 0.25 档、冷门升半级；赛季末保级 / 争冠期平局权重下调；国家队比赛日后首轮体能损耗 1 档、进球下调 0.5 档。
3. **联赛专属规则边界**：韩 K 专属规则适用于 K1、K2 联赛；杯赛、季后赛仅作参考，优先通用规则。
4. **中立场定义**：非常规主场 + 无主队球迷氛围，同时满足才触发中立场规则；本国异地客场不算中立场。
5. **深浅盘判定**：高于基准线≥0.25 球为深盘，±0.25 球内为中盘，低于基准线≥0.25 球为浅盘。
6. **规则优先级**：核心伤停 / 首发变阵 > 赛制属性 > 联赛专属规则 > 通用盘口规则 > 试运行规则。

## 第二部分 赛前标准化分析流程（6 步闭环）

### 第一步：赛前规则预检与场景匹配

1. **数据质量评估与兜底**：确认四大核心维度完整性，剔除异常机构；机构不足 3 家则全部信号降为弱信号；盘口跳变≥1 球无基本面支撑则放弃让球方向判定。
2. **赛制属性匹配**：确认赛制、场地、主客场、客场进球规则；按杯赛首回合 / 次回合对应调整进球与平局权重；划分联赛稳定性与阶段属性。
3. **强弱层级校验**：估算身价差，判定常规 / 碾压级；执行强队脱敏前置校验（R39），匹配对应逻辑；预判合理盘口区间。

表格

| 身价差倍数 | 合理盘口（主客场） |
| --- | --- |
| 1-1.5 倍 | 平手盘 |
| 1.5-3 倍 | 平半盘 |
| 3-5 倍 | 半球盘 |
| 5-10 倍 | 半一盘 |
| ≥10 倍 | 一球及以上（碾压级） |

4. **专项风险触发**：交叉盘场次信号自动降一级；风险场次强制触发赛前 5 步排查操作法（R29）。

### 第二步：胜平负盘性判定

1. **凯利量化计算**：校准后计算平均值、中位值、极差、最大差值；按 0.05 阈值判定平权 / 倾斜，倾斜盘分轻度（0.06-0.10）、中度（0.11-0.20）、重度（≥0.20）三级。
2. **背离校验**：赔率凯利同向且加速下行则权重升半级；背离场景不调整权重。
3. **平局 / 冷门权重校验**：按联赛稳定性对应规则执行；通用冷门信号累计触发，分级调整冷门顺位；满足大热必死量化条件则冷门权重升半级。
4. **离散度映射**：极差≤0.05 为极强共识，对应方向权重前置；0.06-0.15 为中等共识；≥0.16 为弱共识。
5. **平权盘分型**：按人气差与身价差，分为筹码平衡型（严格三项并列）与实力对冲型（可微调平局权重）。

### 第三步：让球盘双向阻诱拆解

1. **初盘定位校验**：结合身价差、排名、交锋得出合理盘口；按主客场转换标准判定深开 / 浅开；验证盘口偏离是否有基本面支撑，无支撑才判定为操盘导致。
2. **有效异动判定（R05）**
   - 触发条件：3 家及以上同向盘口变动≥0.25 球，或水位变动达到对应阈值（深盘≥0.12、中盘≥0.15、浅盘≥0.18）。
   - 辅助判定：需连续变动才算有效；极速跳变、震荡诱盘、反复横跳均判定为分歧，信号降级；半盘水位按 0.7 系数折算。
3. **阻诱细分定性**：升盘升水为阻上，升盘降水≥0.08 为真实看好；退盘升水为真实示弱，退盘降水为诱下；横盘单向变动对应调整权重。
4. **反证校验**：凯利同步下行、必发烧度走低、有基本面支撑，三种情况阻诱结论不成立，需重判。
5. **容错权重计算**：按盘口类型计算平局与走水权重；走水占比高的盘口信号降半级。
6. **专项规则二次校验**：深盘跨层级豁免、退档诱穿、超高水分级、韩 K 专属、半球盘降级、分歧盘降级，逐一校验边界。
7. **欧赔 - 亚盘联动校验（R12）**：换算理论合理水位，偏差≥0.08 且反向则判定背离，信号降级。

### 第四步：总进球专项分析（三步法）

**权重分配：基本面 60% + 盘口风控 30% + 反向校验 10%**

1. **第一步：基本面定基调**
   - 联赛基准线：近 2 赛季 ×40% + 本赛季 ×60%；杯赛取近 3 届同阶段数据。
   - 攻防量化 + 主帅风格 + 交锋克制 + 战术组合，综合修正基础区间。
   - 辅助修正：裁判尺度、短期走势惯性、交锋往绩惯性、战意等级、赛程体能、伤停轮换、天气场地、定位球属性；单项修正幅度严格对应标准，总叠加不超 1 档。
2. **第二步：盘口水位验风控**
   - 按共识 / 分歧 / 异常盘分类处理，对应调整信号等级。
   - 按深浅盘匹配对应水位阈值，判定信号强度。
   - 双盘联动验证，水位差过小则判定分歧、信号降级。
   - 专项规则校验：深盘大球超低水诱盘（R17，2.5 球及以上 + 大球初始水位≤0.65）、浅盘小球超高水诱盘、平局双校验、韩 K 专属规则。
   - 信号等级对应理论命中率：强信号≈90%+，中信号≈75%，弱信号≈55%-60%。
3. **第三步：反向因素校验**
   - 按强 / 中 / 弱三级对应放宽容错幅度。
   - 执行非对称容错调整（R22）：反向异动仅放宽反向边界，同向异动仅收窄反向边界。

### 第五步：惯性校验与终审通关（一票否决制）

1. 7 类常规惯性校验，全部通过方可进入下一环节。
2. 深盘 / 强弱对阵强制路径依赖反向测试：反向赛果需至少 2 条战术支撑，不通过则驳回结论。
3. 规则冲突管控：调用规则前先校验禁用反例；核心规则反向冲突则全部信号降级；严格执行权重叠加上限（R38）。
4. 平权盘单选禁令（R40）：极致平权盘禁止胜平负单选，为一票否决项。
5. 跨维度一致性校验：3 维全背离判定为逻辑矛盾，全部降为弱信号。
6. 终审三问：反向有合理解释、互换队名逻辑一致、全部调整有规则依据；任一不通过则驳回。

### 第六步：综合结论输出

1. 开头强制标注对阵双方、数据截止时间、规则版本号。
2. 胜平负、让球、总进球三个维度输出结论，标注对应规则编号；单场最多输出 2 个明确方向，禁止三维度同时强偏向。
3. 比分梯队严格执行 3+3+3 结构，净胜 2 球双向覆盖；冷门权重对应梯队顺位。
4. 附加半场参考结论。
5. 核心数据（凯利、信号等级、比分梯队、伤停损耗）必须表格化呈现。

## 第三部分 临盘与半场更新流程

### 一、赛前临盘更新

1. 仅开赛 2 小时内异动有效；早盘 / 中盘波动不调整。
2. 开赛 15 分钟内极速变动≥0.10，视同满足中盘阈值，信号升半级；仍不得反转核心方向。
3. 首发校验：核心缺阵对应损耗档位，极端变阵调整进球区间；常规轮换不调整核心结论。
4. 降赔付真伪鉴别：大额急降 + 凯利同步为真，缓慢阴跌 + 凯利不动为假。
5. 调整规则：同向升级收窄容错，反向降级放宽容错；全程不反转核心方向。

### 二、半场数据更新

1. 按半场比分预判下半场战术倾向，对应调整进球节奏预期。
2. 半场偏差≥2 球，全场容错放宽 1 档，不反转方向。
3. 半场红牌最多调整 1 档权重；75 分钟后红牌视为随机事件，不调整。
4. 半场不得推翻赛前核心方向，仅调整区间与容错。

## 第四部分 赛后复盘与规则迭代

### 一、单场复盘七步法

1. **数据录入**：必填比赛时间、赛事类型、对阵双方；补充赛果、半场比分、关键事件、进球分布、场面数据。
2. **还原结论**：完整复现赛前结论，禁止事后修正。
3. **分维度命中判定**：盘性、让球、总进球、容错、胜平负覆盖、比分梯队、半场维度。
4. **四分类归因（R30）**：规则类 / 执行类 / 认知类 / 随机类；仅规则类可提优化建议，随机类不修改规则。
5. **战术兑现度评估**：场面符合预判仅进球偏差归随机类；战术节奏完全偏离归认知 / 规则类。
6. **固化规则适配验证**：
   - 记录每条触发规则的适配效果；
   - 同步校验规则调用合规性：本场调用规则是否符合适用场景、是否触发禁用反例；
   - 若属于错误套用禁用反例导致的偏差，归为执行类问题，不判定为规则逻辑缺陷。
7. **优化建议**：单场发现仅可暂存，不得直接固化规则（R33 前置约束）。

### 二、试运行规则迭代

1. **样本统计（执行 R34 命中率统一标准）**
   - **基准命中率**：总进球方向≈60%，平局≈30%，作为规则效果对比基准。
   - **统计口径**：①方向命中率（方向正确即命中，含容错区间）；②核心区间命中率（赛果落在核心区间内）；③比分命中率（核心比分命中）。
   - **异常样本剔除（通用规则）**：出现以下三类极端随机事件的场次，可标记为异常样本，不计入所有规则的命中率统计：①出现红牌且直接影响赛果；②补时阶段点球 / 绝杀逆转；③门将重大失误、乌龙球等非战术性丢球占比≥50%。
2. **退出机制**：同场景≥8 场命中率提升＜5%，或连续 3 场全反向，退出试运行库。
3. **固化升级流程（R33）**
   - 样本量达标：同场景≥10 场，命中率提升满足差异化阈值（平局规则≥12%，大小球规则≥10%）；
   - 跨联赛泛化验证→材料准备→第一次确认→第二次确认→正式入库。
4. **失效评审**：已固化规则连续 5 场全反向，启动失效评审；确属逻辑缺陷的，按二次确认原则提交调整；评审期暂停强制触发。
5. **适配率统计**：每条已固化规则单独记录适配场次、命中情况；每月统计适配命中率，持续下滑的规则启动失效评审。

### 三、体系维护（精简保留核心要求）

1. 月度全局复盘：统计整体命中率、规则适配率、偏差分布，评估试运行规则进度，输出优化报告。
2. 偏差整改闭环：执行类偏差补入自检清单，认知类偏差录入反例库；同类偏差≥3 次优化对应流程。
3. **复盘禁止项（R32）**：禁止事后倒推归因、禁止赛果反判定性、禁止忽略随机事件强行归因。

## 第五部分 输出强制规范

1. **对阵前置**：结论开头必须标注「主队 vs 客队」。
2. **核心数据表格化（R37）**：凯利、信号等级、比分梯队、伤停损耗、命中统计五类必须表格呈现。
