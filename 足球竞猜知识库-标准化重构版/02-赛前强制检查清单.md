# 赛前强制检查清单

## A. 数据与场景

- [ ] 对阵、赛事类型、开赛时间、数据截止时间完整。
- [ ] 受注初盘、临盘盘口、各阶段水位和变盘时序完整。
- [ ] 核心机构数量不少于 3 家；异常机构已标记。
- [ ] 联赛稳定性、赛季阶段、主客场、中立场和杯赛属性已确认。
- [ ] 强弱层级与合理盘口基准已完成校验。

## B. 三维分析

- [ ] 胜平负：欧赔、凯利、平权/倾斜、平局/冷门信号已交叉验证。
- [ ] 亚盘：档位变化优先，水位变化辅助，阻盘/诱盘已完成双向校验。
- [ ] 大小球：基本面基准、盘口水位、双盘口联动和反向因素已独立判断。
- [ ] 已区分赢球与赢盘，未把胜负盘结论线性推导为总进球结论。

## C. 风险与冲突

- [ ] 对应联赛和赛事类型专项规则已检索。
- [ ] 对应盘型专项规则已检索。
- [ ] 每条命中规则的禁用条件和例外已检查。
- [ ] 重复规则、补充规则和冲突组已检查。
- [ ] 权重叠加未超过上限；灰色震荡区间已降级提示。
- [ ] 临盘生命线已明确：档位反转、水位强化、中性震荡。

## D. 输出

- [ ] 结论标注规则编号、来源编号和数据截止时间。
- [ ] 最多输出两个明确方向，不三维度同时强偏向。
- [ ] 比分按梯队输出，保留极端格局容错。
- [ ] 附风险提示，明确为逻辑参考，不构成投注建议。
