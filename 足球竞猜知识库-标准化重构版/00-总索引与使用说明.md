# 足球竞猜知识库-标准化重构版

本库是原知识库 57 份文档的独立重构版本。原始文档不在本库中复制或混用；每份原文对应一份 `SRC-xxx` 来源重建文档，比赛分析默认从规范规则目录和赛前流程入口检索。

## 使用顺序

1. 读取 `01-赛前分析总流程.md`。
2. 读取 `02-赛前强制检查清单.md`。
3. 按联赛、赛制、盘口档位、初盘/即盘、欧赔、凯利、大小球和时间节点检索 `03-规范规则目录/`。
4. 命中重复、补充或冲突关系时读取 `06-冲突与版本登记/`。
5. 需要追溯原始措辞时读取对应的 `04-来源重建文档/SRC-xxx-...md`。
6. 需要类比时读取 `05-案例与复盘库/`，不得用赛果倒推赛前规则。

## 目录说明

- `03-规范规则目录`：唯一的赛前规则快速检索入口；规则状态统一为 effective。
- `04-来源重建文档`：57 份来源逐一重建，完整保留原始正文。
- `05-案例与复盘库`：案例与复盘归档入口。
- `06-冲突与版本登记`：重复、补充、分支和直接冲突登记。
- `98-覆盖率与验收`：57/57 覆盖矩阵、来源反查和隔离验收。

## 生效与冲突原则

所有现有规则按当前生效处理。旧文档中的 `staged`、`trial`、`unverified` 等历史字段不作为新库禁用条件；当同场景规则直接冲突且无法由适用范围或优先级裁决时，冲突组内规则均保留，但本场默认不触发冲突方向，回退通用规则并提升风险提示。
